# Hexproj results

Public static research artifacts: layouts, interactive mesh views, metrics and mesh downloads.

Site: https://rndubs.github.io/hexproj-results/

The mesher source and internal execution records are maintained separately. This repository contains only selected report-linked artifacts. Original session logs, CAD inputs, machine paths and account metadata are excluded.

Geometry acceptance is distinct from visual quality; no human grades are inferred. GPT dollar figures are API equivalents, not subscription invoices.
