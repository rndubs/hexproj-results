Each approach receives identical original CAD. Model authors receive no compiler or other-model layouts. The deterministic mesher compiles the CAD directly. Native quality and exact CAD checks are identical within this experiment; both nominal and doubled densities are independently reread.

Teal line diagrams show author-planned partitions over the gray CAD outline. Colored realized layouts identify source parts, not element quality; a single source part can contain multiple reduced block regions. SJ views share a 0.2–1 scale; larger is better. Meridian mesh views are real cuts through the 3D mesh, offset by 1e-7 of the bounding-box diagonal to avoid ambiguous coplanar faces; degenerate slice polygons are removed. This changes only visualization, not mesh data or SJ. The cuts expose interior cells; isometric views show exposed surfaces. All-cell statistics include hidden cells. Gray views show original CAD tessellation. Half-meridian sections show one side of the rotation axis; through-bores are preserved in both meshes and 3D views.

Astra uses medium reasoning; Opus high. GPT dollars are Standard API-equivalent estimates from cumulative native tokens, Claude dollars are CLI-reported usage; neither is an actual subscription invoice.
